01 — The problem

You chose a dozen packages. You installed hundreds.

Most of the code in your app was written by strangers, and most of it arrived as sub-dependencies you never picked. Attackers don't break into your app — they poison something it depends on, and your own npm install does the rest.

One bad package is enough. It runs with your permissions, on your laptop and your build servers, with your tokens, keys and customer data in reach.

06 — Private by design

Security tooling you don't have to worry about.

Names and versions only

That's all that leaves your machine, plus public CVE ids for EPSS. Never source code, file paths or credentials.

Never runs your code

Manifests are read as text, with size limits and workspace-only file access. Works in Restricted Mode.

HTTPS only

Including every redirect. Plain HTTP is allowed only for a localhost mirror.

Open source, MIT

Read every line. Free data sources: OSV.dev, deps.dev, CISA KEV, FIRST EPSS.
