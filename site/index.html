The problem

You chose a dozen packages.
You installed hundreds.

Most of the code in your app was written by strangers, and most of it arrived as sub-dependencies you never picked. Attackers know this. Instead of breaking into your app, they poison something it depends on, and your own npm install or build does the rest.

One bad package is enough. It runs with your permissions, on your laptop and on your build servers, with access to your tokens, keys and customer data.

    Why developers use DepSentinel

    A security teammate that never sleeps
    and never slows you down.

    Catches attacks with no CVE yet

    Fresh malicious releases have no advisory for hours or days. 15 behavior signals flag them anyway: new install scripts, publisher changes, dropped provenance, typosquats, unexpected registries.

    Tells you what to fix first

    Priority blends severity with CISA KEV, EPSS, runtime vs dev-only, and how easy the fix is. You get a short "start here" list, not a wall of red.

    Lives where you code

    Warnings on the exact dependency line, in Problems, and in a findings view. Press Ctrl+. to upgrade, or to force a safe version of a deep sub-dependency.

    Private by design

    Only package names and versions leave your machine. No account, no API key, no telemetry. It never runs your project's code, and works in Restricted Mode.

    Guard the pipeline too

    Fail the build before it ships.

    The same engine runs as a command-line tool. Add it to CI and a malicious or actively exploited dependency can't sneak into a release.

    ci · build #482
    
      
    
      
    
        
    # .github/workflows/deps.yml
- uses: actions/checkout@v4
- uses: actions/setup-node@v4
  with: { node-version: 22 }
- name: Build DepSentinel CLI
  run: |
    git clone --depth 1 \
      https://github.com/afzaalsatti/dep-sentinel /tmp/ds
    cd /tmp/ds && npm ci && npm run compile
- name: Scan dependencies
  run: >
    node /tmp/ds/dist/cli.js .
    --fail-on high --sarif ds.sarif

    Private by design
